<!-- brief -->

Open and enter a focused direct child task.

<!-- guidance -->

Use `spine_open` as soon as a focused body of work has clear context ownership and an independent lifecycle. The child must own one concrete, independently completable goal whose detailed working context can later be replaced by compact memory.

Valid input:

```json
{"goal":"Inspect reducer behavior"}
```

Keep exact context needed by several branches in their lowest common ancestor. Do not open nodes merely for semantic grouping or progress reporting. The response may contain exactly one Bonsai structural control. Ordinary tool calls issued with `spine_open` belong to the child; the transition applies to the current node's prior ReAct history.
